This is a demo view of estimated emissions for an AWS account. It uses sample data and the Greenpixie API to calculate emissions and visualise their change over time.

How this view grows

Each month, a Lambda joins AWS CUR billing data with Greenpixie rate card data from its API, then publishes emissions totals for this graph.

01 AWS CUR billing → 02 Greenpixie API → 03 Lambda joins data → 04 Emissions graph
